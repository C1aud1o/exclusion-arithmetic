NAME
Number of odd multiples of 5 with exactly n binary digits in the exclusion semiring N_0[x]/(2 = 1 + x) acting on binary expansions.

COMMENTS
Exclusion arithmetic: let S = N_0[x]/(2 = 1 + x) be the commutative semiring of polynomials with nonnegative integer coefficients modulo the congruence generated by 2 = 1 + x. Every class contains exactly one polynomial with all coefficients in {0, 1}; reading it in base 2 (x -> 2) identifies S with the nonnegative integers and equips them with a sum [+] and a product [x]. To compute, add or multiply the binary expansions as polynomials and then normalize from the least significant column upward: a column holding t >= 1 units keeps one unit and passes the other t - 1 to the next column (so 1 [+] 1 = 3 and 3 [x] 3 = 15).
Here 5 is the class of 1 + x^2 and 5 [x] b = b [+] 4*b. The map b -> 5 [x] b is far from injective (5 [x] 7 = 5 [x] 11 = 63) and can lengthen b by more than two digits, so a(n) counts distinct values.
An odd number m is a multiple of 5 in the semiring if and only if the following holds. Read the binary expansion of m from the least significant end as maximal runs of 1's of lengths M_1, ..., M_r separated by maximal runs of 0's of lengths Z_1, ..., Z_(r-1), and put u_0 = 0, u_i = (M_1 + ... + M_i) mod 2. Then (1) u_r = 0; (2) Z_i = 1 whenever u_i = 1; (3) M_i is neither 2 nor 3 whenever u_(i-1) = 0.
The characterization, and with it the recurrence, is proved by a finite computation: the outputs of the multiplication transducer restricted to carries <= 1 and the outputs of its abstraction that remembers carries >= 1 only modulo 2 form the same regular language, whose minimal automaton has 7 states and accepts exactly the words described above; see the link. The counts were also confirmed by direct enumeration of all products for n <= 37.
a(n) <= A??????(count_odd_composites)(n) for n >= 4, since every multiple of 5 other than 5 itself is composite; a(3) = 1 counts 5 itself.
The corresponding count for multiples of 3 = 1 + x (odd numbers with n binary digits in which every run of 1's has even length, cf. A277335) is Fibonacci(n-3) = A000045(n-3) for n >= 3.

FORMULA
a(n) = a(n-1) + a(n-2) + a(n-5) for n >= 6.
G.f.: x^3*(1 - x^2)/(1 - x - x^2 - x^5).
a(n) ~ c*r^n, where r = 1.7049027760... is the real root of x^5 = x^4 + x^3 + 1.

EXAMPLE
a(3) = 1: 5 = 101_2. a(4) = 1: 15 = 5 [x] 3. a(5) = 1: 29 = 5 [x] 5.
a(6) = 2: 45 = 101101_2 = 5 [x] 9 and 63 = 111111_2 = 5 [x] 7.
For 45, reading from the right: M = (1, 2, 1), Z = (1, 1), u = (1, 1, 0); the runs of 0's after u_1 = 1 and u_2 = 1 have length 1, the run of length 2 starts with u_1 = 1, and u_3 = 0.
51 = 110011_2 is not a multiple of 5: its first run of 1's has length 2 and starts with u_0 = 0.

(Python)
def eadd(a, b):  # sum in N_0[x]/(2 = 1 + x); a column keeps 1 unit and carries the rest
    r = c = k = 0
    while a >> k or b >> k or c:
        t = c + (a >> k & 1) + (b >> k & 1)
        if t: r |= 1 << k; c = t - 1
        k += 1
    return r
def a(n):  # by definition: distinct odd n-bit values of 5 [x] b = b [+] 4b
    return len({p for b in range(1, 1 << max(n - 2, 0), 2) if (p := eadd(b, 4 * b)) >> (n - 1) == 1})
print([a(n) for n in range(1, 17)])
