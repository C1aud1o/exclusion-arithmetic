NAME
a(n) = n [+] n, the exclusion-arithmetic double of n, where [+] is addition in the semiring N_0[x]/(2 = 1 + x) acting on binary expansions.

COMMENTS
Exclusion arithmetic: let S = N_0[x]/(2 = 1 + x) be the commutative semiring of polynomials with nonnegative integer coefficients modulo the congruence generated by 2 = 1 + x. Every class contains exactly one polynomial with all coefficients in {0, 1}; reading it in base 2 (x -> 2) identifies S with the nonnegative integers and equips them with a sum [+] and a product [x]. To compute, add or multiply the binary expansions as polynomials and then normalize from the least significant column upward: a column holding t >= 1 units keeps one unit and passes the other t - 1 to the next column (so 1 [+] 1 = 3 and 3 [x] 3 = 15).
Equivalently: write n in binary, replace every digit 1 by 2, and normalize.
a(n) = 3 [x] n, because 1 [+] 1 = 3.
A000120(a(n)) = 2*A000120(n): evaluation at x = 1 (the binary weight) is a semiring homomorphism onto the ordinary nonnegative integers.
a(n) >= 3*n, with equality if and only if n is a fibbinary number (A003714).
The set of values is A277335 (numbers in which every run of 1's has even length); these are the multiples of 3 in the semiring. The map is not injective: a(3) = a(5) = 15.
Agrees with A162276 for 1 <= n <= 10; first differs at n = 11 (a(11) = 63, whereas A162276(11) = 33).

FORMULA
a(n) = 3 [x] n = n [+] 2*n.
a(2*n) = 2*a(n); a(2*n+1) = 2*a(n) [+] 3.
a(2^k) = 3*2^k; a(2^k - 1) = 4^k - 1.
A000120(a(n)) = 2*A000120(n).
n [+] 1 = A086799(n+1).

EXAMPLE
11 = 1011_2 = 1 + x + x^3, so 11 + 11 has column counts 2, 2, 0, 2 (least significant first).
Column 0 holds 2: it keeps 1 and passes 1. Column 1 then holds 3: it keeps 1 and passes 2. Column 2 holds 2 and column 3 holds 3; the two units leaving column 3 fill columns 4 and 5.
All six columns are occupied, so a(11) = 111111_2 = 63.

(Python)
def a(n):
    r = c = k = 0
    while n >> k or c:
        t = c + 2 * (n >> k & 1)  # column k of n + n, plus the incoming carry
        if t: r |= 1 << k; c = t - 1
        k += 1
    return r
print([a(n) for n in range(60)])
