NAME
Odd composite elements of the exclusion semiring N_0[x]/(2 = 1 + x) acting on binary expansions: odd numbers of the form b [x] c with b, c > 1.

DATA

OFFSET
1,1

COMMENTS
Exclusion arithmetic: let S = N_0[x]/(2 = 1 + x) be the commutative semiring of polynomials with nonnegative integer coefficients modulo the congruence generated by 2 = 1 + x. Every class contains exactly one polynomial with all coefficients in {0, 1}; reading it in base 2 (x -> 2) identifies S with the nonnegative integers and equips them with a sum [+] and a product [x]. To compute, add or multiply the binary expansions as polynomials and then normalize from the least significant column upward: a column holding t >= 1 units keeps one unit and passes the other t - 1 to the next column (so 1 [+] 1 = 3 and 3 [x] 3 = 15).
The only unit is 1. An element m > 1 is composite if m = b [x] c with b, c > 1, and irreducible otherwise.
2 (the class of x) is the unique prime element of the semiring, that is, the only p > 1 such that p divides b [x] c only if p divides b or c. Since 2 [x] m = 2*m, the even composites are exactly the even numbers >= 4; therefore only the odd composites are listed here.
The binary weight is multiplicative, A000120(b [x] c) = A000120(b)*A000120(c), so every term has composite binary weight. The converse fails: 23 = 10111_2 has weight 4 but is irreducible.
Factorization into irreducibles is not unique and cancellation fails: 15 = 3 [x] 3 = 3 [x] 5.
Contains every odd term > 3 of A277335 (the multiples of 3 in the semiring).
The density of the terms decays exponentially: the number of terms with exactly n binary digits is at most (n + o(1))*2^(H*n) with H = log_2(3) - 2/3 = 0.9182..., whereas there are 2^(n-2) odd numbers with n binary digits. (A composite of weight W either has W >= 2n/3 or has a factor of weight at most W/2 < n/3.)

EXAMPLE
15 = 1111_2 is a term: 3 [x] 3 = (1 + x)^2 = 1 + 2*x + x^2 = 1 + x + 2*x^2 = 1 + x + x^2 + x^3. Also 15 = 3 [x] 5.
27 = 11011_2 = 3 [x] 9, 29 = 11101_2 = 5 [x] 5 and 45 = 101101_2 = 5 [x] 9 are terms.
23 = 10111_2 is not a term: a factorization would need two odd factors of weight 2 with at most 6 binary digits in total, but 3 [x] 3 = 3 [x] 5 = 15, 3 [x] 9 = 27 and 5 [x] 5 = 29.

(Python)
def emul(a, b):  # product in N_0[x]/(2 = 1 + x); a column keeps 1 unit and carries the rest
    r = c = k = 0
    while k < a.bit_length() + b.bit_length() or c:
        t = c + sum(1 for i in range(k + 1) if a >> i & b >> (k - i) & 1)
        if t: r |= 1 << k; c = t - 1
        k += 1
    return r
def composites(nb):  # all odd composites below 2^nb
    s = set()
    for b in range(3, 1 << (nb + 1) // 2, 2):
        for c in range(b, 1 << nb + 1 - b.bit_length(), 2):
            p = emul(b, c)
            if p < 1 << nb: s.add(p)
    return s
print(sorted(composites(9)))
