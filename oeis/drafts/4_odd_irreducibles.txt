NAME
Odd irreducible elements of the exclusion semiring N_0[x]/(2 = 1 + x) acting on binary expansions: odd numbers m > 1 that are not of the form b [x] c with b, c > 1.

OFFSET
1,1

COMMENTS
Exclusion arithmetic: let S = N_0[x]/(2 = 1 + x) be the commutative semiring of polynomials with nonnegative integer coefficients modulo the congruence generated by 2 = 1 + x. Every class contains exactly one polynomial with all coefficients in {0, 1}; reading it in base 2 (x -> 2) identifies S with the nonnegative integers and equips them with a sum [+] and a product [x]. To compute, add or multiply the binary expansions as polynomials and then normalize from the least significant column upward: a column holding t >= 1 units keeps one unit and passes the other t - 1 to the next column (so 1 [+] 1 = 3 and 3 [x] 3 = 15).
The odd numbers > 1 that are not in A??????(odd_composites).
The only even irreducible element is 2, which is also the only prime element. No term is prime in the semiring; for example 3 divides 5 [x] 7 = 63 = 3 [x] 21 but divides neither 5 nor 7.
Contains every odd number with a prime number of 1's in binary (the odd terms of A052294), because the binary weight is multiplicative: A000120(b [x] c) = A000120(b)*A000120(c).
Contains every odd m > 1 with 2*A007814(m-1) > A000523(m), that is, whose two lowest 1 bits are farther apart than half the position of its highest 1 bit (the gap between the two lowest 1 bits of b [x] c is the smaller of the gaps of b and c). There are 2^(floor(n/2)-1) such m with n binary digits.
The terms have asymptotic density 1 among the odd numbers: at most 2^(0.8747*n + o(n)) of the 2^(n-2) odd numbers with n binary digits are composite.
For the analogous notion in dismal (lunar, OR-numbral) base-2 arithmetic, where 1 + 1 = 1 replaces 1 + 1 = 1 + x, see A067139.

EXAMPLE
7 = 111_2 has binary weight 3, a prime, so it is a term.
23 = 10111_2 has weight 4 but is a term: the only products of two odd elements of weight 2 with at most 6 binary digits in total are 3 [x] 3 = 3 [x] 5 = 15, 3 [x] 9 = 27 and 5 [x] 5 = 29.
15 = 3 [x] 3 and 27 = 3 [x] 9 are not terms.

def emul(a, b):  # product in N_0[x]/(2 = 1 + x); a column keeps 1 unit and carries the rest
    r = c = k = 0
    while k < a.bit_length() + b.bit_length() or c:
        t = c + sum(1 for i in range(k + 1) if a >> i & b >> (k - i) & 1)
        if t: r |= 1 << k; c = t - 1
        k += 1
    return r
def composites(nb):  # all odd composites below 2^nb
    s = set()
    for b in range(3, 1 << (nb + 1) // 2, 2):
        for c in range(b, 1 << nb + 1 - b.bit_length(), 2):
            p = emul(b, c)
            if p < 1 << nb: s.add(p)
    return s
print(sorted(set(range(3, 512, 2)) - composites(9)))
