NAME
a(n) = n [x] n, the exclusion-arithmetic square of n, where [x] is multiplication in the semiring N_0[x]/(2 = 1 + x) acting on binary expansions.

COMMENTS
Exclusion arithmetic: let S = N_0[x]/(2 = 1 + x) be the commutative semiring of polynomials with nonnegative integer coefficients modulo the congruence generated by 2 = 1 + x. Every class contains exactly one polynomial with all coefficients in {0, 1}; reading it in base 2 (x -> 2) identifies S with the nonnegative integers and equips them with a sum [+] and a product [x]. To compute, add or multiply the binary expansions as polynomials and then normalize from the least significant column upward: a column holding t >= 1 units keeps one unit and passes the other t - 1 to the next column (so 1 [+] 1 = 3 and 3 [x] 3 = 15).
A000120(a(n)) = A000120(n)^2: evaluation at x = 1 (the binary weight) is a semiring homomorphism onto the ordinary nonnegative integers.
a(n) >= n^2, with equality if and only if n = 0 or n is a power of 2.
The map is not injective: a(7) = a(11) = 511 is the first repeated value.
a(n) has at least 2*L - 1 binary digits, where L is the number of binary digits of n.

FORMULA
a(2*n) = 4*a(n).
a(2^k) = 4^k; a(2^k - 1) = 2^(k^2) - 1.
a(2^k + 1) = 4^k + 3*2^k + 1 for k >= 2.
A000120(a(n)) = A000120(n)^2.

EXAMPLE
3 = 11_2 = 1 + x and (1 + x)^2 = 1 + 2*x + x^2, with column counts 1, 2, 1.
Column 1 holds 2: it keeps 1 and passes 1. Column 2 then holds 2: it keeps 1 and passes 1 to column 3.
So a(3) = 1111_2 = 15.
Similarly 7 = 111_2 gives column counts 1, 2, 3, 2, 1, nine units in all, which fill nine consecutive columns: a(7) = 2^9 - 1 = 511.

(Python)
def emul(a, b):  # product in N_0[x]/(2 = 1 + x); a column keeps 1 unit and carries the rest
    r = c = k = 0
    while k < a.bit_length() + b.bit_length() or c:
        t = c + sum(1 for i in range(k + 1) if a >> i & b >> (k - i) & 1)
        if t: r |= 1 << k; c = t - 1
        k += 1
    return r
print([emul(n, n) for n in range(50)])
