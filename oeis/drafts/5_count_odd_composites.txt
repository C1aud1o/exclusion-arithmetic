NAME
Number of odd composite elements with exactly n binary digits in the exclusion semiring N_0[x]/(2 = 1 + x) acting on binary expansions.

COMMENTS
Exclusion arithmetic: let S = N_0[x]/(2 = 1 + x) be the commutative semiring of polynomials with nonnegative integer coefficients modulo the congruence generated by 2 = 1 + x. Every class contains exactly one polynomial with all coefficients in {0, 1}; reading it in base 2 (x -> 2) identifies S with the nonnegative integers and equips them with a sum [+] and a product [x]. To compute, add or multiply the binary expansions as polynomials and then normalize from the least significant column upward: a column holding t >= 1 units keeps one unit and passes the other t - 1 to the next column (so 1 [+] 1 = 3 and 3 [x] 3 = 15).
a(n) is the number of terms m of A??????(odd_composites) with 2^(n-1) < m < 2^n. Even numbers are composite if and only if they are >= 4, so only odd elements are counted.
Proved bounds: A??????(multiples_of_5)(n) <= a(n) for n >= 4 (every multiple of 5 other than 5 itself is composite), and a(n) <= (n + o(1))*2^(H*n) with H = log_2(3) - 2/3 = 0.9182958..., the binary entropy of 1/3. Hence lim inf a(n)^(1/n) >= 1.7049027... (the real root of x^5 = x^4 + x^3 + 1) and lim sup a(n)^(1/n) <= 2^H = 1.8898..., so the proportion a(n)/2^(n-2) of composites among the odd n-digit numbers tends to 0 exponentially fast.
Sketch of the upper bound: the binary weight is multiplicative, so an odd composite with n digits and weight W either has W >= 2n/3, or is b [x] c with b of weight 2 and c of weight W/2 < n/3, or is b [x] c with b of weight less than sqrt(n) and c of weight less than 2n/9. There are at most 2^(H*n) numbers of the first kind, n*2^(H*n) of the second and 2^(0.7643*n + o(n)) of the third.
Terms a(1)..a(37) were computed by an exhaustive sieve over all products; see the link.

def emul(a, b):  # product in N_0[x]/(2 = 1 + x); a column keeps 1 unit and carries the rest
    r = c = k = 0
    while k < a.bit_length() + b.bit_length() or c:
        t = c + sum(1 for i in range(k + 1) if a >> i & b >> (k - i) & 1)
        if t: r |= 1 << k; c = t - 1
        k += 1
    return r
def composites(nb):  # all odd composites below 2^nb
    s = set()
    for b in range(3, 1 << (nb + 1) // 2, 2):
        for c in range(b, 1 << nb + 1 - b.bit_length(), 2):
            p = emul(b, c)
            if p < 1 << nb: s.add(p)
    return s
def a(n): return sum(1 for m in composites(n) if m >> (n - 1))
