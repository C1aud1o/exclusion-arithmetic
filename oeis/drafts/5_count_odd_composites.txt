NAME

COMMENTS
Exclusion arithmetic: let S = N_0[x]/(2 = 1 + x) be the commutative semiring of polynomials with nonnegative integer coefficients modulo the congruence generated by 2 = 1 + x. Every class contains exactly one polynomial with all coefficients in {0, 1}; reading it in base 2 (x -> 2) identifies S with the nonnegative integers and equips them with a sum [+] and a product [x]. To compute, add or multiply the binary expansions as polynomials and then normalize from the least significant column upward: a column holding t >= 1 units keeps one unit and passes the other t - 1 to the next column (so 1 [+] 1 = 3 and 3 [x] 3 = 15).
a(n) is the number of terms m of A??????(odd_composites) with 2^(n-1) < m < 2^n. Even numbers are composite if and only if they are >= 4, so only odd elements are counted.
Proved bounds: 0.8061 <= lim inf log_2(a(n))/n and lim sup log_2(a(n))/n <= 0.8747. In particular the proportion a(n)/2^(n-2) of composites among the odd n-digit numbers tends to 0 exponentially fast.
Lower bound: every multiple of d other than d itself is composite, so a(n) >= D_d(n) - 1, where D_d(n) is the number of odd multiples of d with n binary digits. For d = 2^s + 1 the multiples form a regular language; this is certified by a finite computation showing that the outputs of the multiplication transducer with carries <= K coincide with those of an abstraction that remembers larger carries only modulo 2. For d = 65 (s = 6, K = 3) the minimal automaton has 1292 states and D_65(n) grows like r^n with r = 1.748494..., log_2(r) = 0.806113... For d = 5, 9, 17, 33 the exponents are 0.769689, 0.791046, 0.799703, 0.803880.
Upper bound: let N = b [x] c be an odd composite with n binary digits, with binary weights wt(b) <= wt(c). If wt(b) = 2 then b = 1 + 2^r, and c may be taken to be the largest cofactor of N. This cofactor never has three 1's at positions i - r, i, i + r, because (1 + x^r)*(x^(i-r) + x^i + x^(i+r)) = (1 + x^r)*(x^(i-r) + x^(i+1) + x^(i+r)) in the semiring and moving the middle 1 one place up increases c. Binary words without three consecutive 1's, each 1 weighted by t, grow like L(t)^n, where L^3 = L^2 + t*L + t^2 (a weighted tribonacci recurrence); hence there are at most t^(-W/2)*L(t)^n such N of weight W, and at most binomial(n, W) numbers of weight W in all. The two bounds balance at W/n = 0.705340..., t = 0.808173..., where both equal 2^(E*n) with E = 0.874664... If wt(b) >= 3, counting weights alone gives at most 2^(H(1/4)*n + o(n)) composites, H(1/4) = 0.811278... being the binary entropy of 1/4.
The computed terms are still far from the asymptotic regime: log_2(a(n)/a(n-1)) is about 0.783 at n = 37, below the proved lower bound, because the multiples of 2^s + 1 with large s, which dominate eventually, are still rare at this size.
Terms a(1)..a(37) were computed by an exhaustive sieve over all products; see the link.

def emul(a, b):  # product in N_0[x]/(2 = 1 + x); a column keeps 1 unit and carries the rest
    r = c = k = 0
    while k < a.bit_length() + b.bit_length() or c:
        t = c + sum(1 for i in range(k + 1) if a >> i & b >> (k - i) & 1)
        if t: r |= 1 << k; c = t - 1
        k += 1
    return r
def composites(nb):  # all odd composites below 2^nb
    s = set()
    for b in range(3, 1 << (nb + 1) // 2, 2):
        for c in range(b, 1 << nb + 1 - b.bit_length(), 2):
            p = emul(b, c)
            if p < 1 << nb: s.add(p)
    return s
def a(n): return sum(1 for m in composites(n) if m >> (n - 1))
print([a(n) for n in range(1, 14)])
